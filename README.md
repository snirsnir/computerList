# מיפוי וניהול מחשבים — טכנודע

מיפוי מלאי המחשבים בטכנודע, דירוג דחיפות החלפה, תוכנית עבודה רב-שנתית ומערכת ניהול לשיוך מחשבים למתחמים.

## הקבצים

| קובץ | תיאור |
|---|---|
| `index.html` | **תוכנית עבודה 2026–2028** — מצגת להנהלה: שלושה שלבי החלפה, סיכום תקציבי וגרפים |
| `index2.html` | **מערכת ניהול מחשבים** — שיוך מחשבים למתחמים בגרירה, חישוב גיל, ייצוא לאקסל, סנכרון Firebase |
| `טבלת מיפוי מחשבים - דחיפות החלפה.xlsx` | טבלת המיפוי המלאה: 113 עמדות / 218 מחשבים, ממוינת וצבועה לפי אופק החלפה |
| `table.xlsx` | עותק של טבלת המיפוי בשם באנגלית (לקישור ישיר) |
| `טבלת מיפוי מחשבים כל הטכנודע 4.2026.xlsx` | קובץ המקור המקורי |
| `computers.json` | הנתונים בפורמט JSON — מקור הזריעה של המערכת |
| `comp.csv`, `comp_with_urgency.csv` | גרסאות CSV של המיפוי |
| `export.png` | תבנית פורמט הייצוא לאקסל |

## מערכת הניהול (`index2.html`)

- **מתחמים** — יצירת מתחמים ושיוך מחשבים אליהם בגרירה
- **גיל מחשב** — מחושב משנת ההשקה של דור המעבד מול שנת 2026
- **סיווג לסוגים** — נייח משרדי / נייד משרדי / נייח מעבד חזק לחוגים
- **ייצוא לאקסל** — שלושה גיליונות: סטטוס לפי מתחם, פירוט מלא, סיכום גילאים
- **אחסון** — Firebase Realtime Database, עם נפילה חלקה ל-localStorage אם אין חיבור
